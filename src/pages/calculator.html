    Формула конкурсного бала 2026

    КБ = (К1·П1 + К2·П2 + К3·П3 + К4·П4) / (К1 + К2 + К3 + (К4max + К4) / 2) × ГК
    П1–П4 - бали НМТ з української мови, математики, історії України та четвертого предмета; К1–К4 - коефіцієнти спеціальності; К4max - найбільший коефіцієнт серед четвертих предметів; ГК - галузевий коефіцієнт 1,02 для спеціальностей із галузевою підтримкою при пріоритеті 1–2. Для НМТ 2024 знаменник - К1+К2+К3+К4, для НМТ 2023 - три предмети.
