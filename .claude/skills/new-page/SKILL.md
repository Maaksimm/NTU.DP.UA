Create a new page: $ARGUMENTS

1. Copy `src/pages/sources.html` to `src/pages/<name>.html`. Edit its front matter: `title`, `description` (<= 160 chars), `page` (unique key, also used as `data-nav`), `breadcrumbs`, optionally `image`, `scripts`, `sitemap`, `robots`. Replace the content after the front matter (`<main id="main">...</main>`). Header, footer, `<head>`, sitemap entry and asset links are generated by `tools/build.mjs` - never write them by hand.
2. Use component classes from `src/styles/`; add CSS only if nothing fits, in the matching module (or a new numbered file), using CSS variables so the dark theme works.
3. Add the page to `src/data/menu.json` (group `items`: `nav` = the page key, `href`, `label`, `desc`) - it then appears in the mega menu, mobile menu and footer of every page - and to the site map section of `src/pages/sections.html`.
4. Add translations (see `add-translation`).
5. `npm run check` must pass with 0 errors; then run the `page-reviewer` agent.
